# 🤖 Jarvis - AI Telegram Assistant Bot

Jarvis is an intelligent Telegram-based personal assistant designed to perform everyday computer and AI-powered tasks through simple chat commands. Built with Node.js, it combines automation, artificial intelligence, and memory capabilities to create a smart assistant experience.

## ✨ Features

### 🧠 AI Conversation & Search
- Natural conversation with Gemini AI
- Web search and information summarization
- Intelligent question answering
- Context-aware responses

### 🧾 Smart Memory System
- Store personal information by category
- Persistent memory across sessions
- Easy recall of stored information
- Organized memory management

### 💻 System Control
- Execute Windows commands remotely
- Open applications and files
- Run scripts and batch files
- Full system access (configurable)

### 📸 Screenshot Monitoring
- Take screenshots on demand
- Periodic monitoring with custom intervals
- Automatic image delivery to Telegram
- Remote system monitoring

### 🔊 Text-to-Speech
- Convert text messages to speech
- High-quality voice synthesis
- Voice message delivery in Telegram
- Accessibility support

## 🚀 Quick Start

### Prerequisites
- Node.js 16+ installed
- Telegram Bot Token (from @BotFather)
- Supabase account for database
- Gemini AI API key
